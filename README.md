# 🌟 Project Overview
Il Progetto FSL è stato creato per permettere la gestione dei dati necessari per i tirocini e i corsi di sicurezza dell'IIS Galileo Galilei

## 🚀 Funzionalità
* Sistema di Autenticazione e Autorizzazione
* API di Backend con PHP
* Frontend con Typescript
* NPM per il package management
* Misure di sicurezza e controllo degli accessi avanzati

## 🛠️ Tech Stack
* Frontend: Vue.js, TypeScript, TailwindCSS
* Backend: PHP
* Database: MySQL
* Build Tools: npm
* Security: Controllo degli accessi, Autenticazione e Autorizzazione

## 📦 Installation
Seguire questi passaggi per installare il progetto:
1. Clonare la repository utilizzando `git clone`
2. Installare le dipendenze utilizzando `npm install`
3. Configurare il database fornito
4. Copiare la cartella api presente nel percorso /src-php/ dentro la cartella htdocs del proprio server apache

## 💻 Usage
Seguire questi passaggi per avviare il progetto:
1. Avviare il dev server utilizzando `npm run dev` 
2. Accedere all'applicazione tramite un browser all'indirizzo web fornito
3. Interagire con l'applicazione
